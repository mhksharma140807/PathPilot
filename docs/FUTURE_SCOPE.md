# PathPilot Post-V2 Roadmap & Future Scope

This document outlines realistic post-V2 enhancements for the PathPilot platform.

---

## 1. Machine Learning & AI Recommendations

- **AI-Powered Skill Gap Analysis**: Machine learning models analyzing candidate resumes and target job listings to recommend optimal career tracks.
- **Adaptive Learning Pathways**: Dynamic adjustment of lesson ordering based on student quiz performance and background experience.

---

## 2. Interactive Assessments & Quizzes

- **End-of-Module Knowledge Checks**: In-app multiple choice quizzes to validate lesson comprehension before marking progress.
- **Automated Coding Sandbox**: Browser-based code evaluation sandbox for interactive coding lessons.

---

## 3. Specialized Role Portals

- **Dedicated Teacher Portal**: Full dashboard allowing instructors to monitor student cohorts, review submitted code tasks, and issue custom phase feedback (building on the scaffolded `teacher` role).
- **Dedicated Parent Portal**: Summary views for parents to monitor learning hours and progress milestones (building on the scaffolded `parent` role).

---

## 4. Analytics & Community Features

- **Advanced Student Learning Analytics**: Visual charts tracking weekly study time, learning velocity, and peak activity hours.
- **Peer Code Review & Discussion Boards**: Forum threads attached to individual modules for student discussion and code sharing.
- **Learning Streaks & Gamification**: Daily activity streaks, milestone badges, and leaderboard systems to boost engagement.

---

## 5. DevOps & Infrastructure

- **Automated CI/CD Pipelines**: GitHub Actions workflows for automated client build verification and unit test execution.
- **Real-Time WebSockets**: Live notifications when milestone achievements are unlocked or new modules are published.
